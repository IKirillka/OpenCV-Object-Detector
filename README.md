# OpenCV Object Detector

Приложение на Python и OpenCV для поиска объектов на изображении, определения
их центров и визуализации ориентации. Объекты с похожей формой получают
одинаковый ID в пределах одного кадра.

## Возможности

- приведение входного изображения к разрешению 640x480;
- поиск внешних контуров и фильтрация мелкого шума;
- построение повернутой рамки вокруг каждого объекта;
- отображение осей ориентации объекта;
- вычисление координат центра в пикселях;
- присвоение одинакового ID объектам с похожими контурами;
- исключение вложенных контуров, например отверстий внутри детали;
- сохранение размеченного изображения;
- визуальная отладка всех этапов обработки.

## Структура проекта

- `detect_objects.py` — основной файл запуска;
- `object_detector.py` — обработка изображения и классификация контуров;
- `visual_debug.py` — отдельный режим визуальной отладки;
- `images/` — тестовые и пользовательские изображения.

## Установка

Создайте и активируйте виртуальное окружение:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Установите зависимости через Python активного окружения:

```powershell
python -m pip install opencv-python numpy imutils
```

## Запуск

Обнаружение объектов:

```powershell
python detect_objects.py --image images/example_01.png
```

Сохранение размеченного кадра:

```powershell
python detect_objects.py --image images/example_01.png --output result.png
```

Пример вывода в консоль:

```text
Object 1: id=1, center=(70, 246) px
Object 2: id=2, center=(285, 146) px
```

## Координаты

Координаты вычисляются после изменения разрешения кадра до 640x480:

- `(0, 0)` находится в левом верхнем углу;
- координата X увеличивается вправо;
- координата Y увеличивается вниз;
- желтая точка показывает центр повернутой рамки;
- красная подпись содержит ID и координаты центра.

## Одинаковые ID

ID назначается по сходству формы контуров. Поэтому несколько похожих круглых
деталей получат один ID, а прямоугольный объект — другой. Порог сходства можно
изменить:

```powershell
python detect_objects.py --image images/example_01.png --similarity-threshold 0.05
```

Меньшее значение требует более точного совпадения формы. Большее значение
объединяет больше отличающихся контуров. Это визуальная классификация внутри
одного кадра, а не распознавание семантических названий предметов.

## Фильтрация шума

По умолчанию игнорируются контуры площадью менее 500 пикселей. Порог можно
изменить:

```powershell
python detect_objects.py --image images/example_01.png --min-area 1000
```

## Визуальная отладка

Показать единую панель с исходным изображением, grayscale, Gaussian Blur,
Canny, морфологической обработкой и итоговой разметкой:

```powershell
python detect_objects.py --image images/example_01.png --debug
```

Сохранить панель отладки:

```powershell
python detect_objects.py --image images/example_01.png --debug-output debug.png
```

Также можно использовать отдельный файл:

```powershell
python visual_debug.py --image images/example_01.png --output debug.png
```

## Основные параметры

```text
--image PATH                    путь к изображению
--output PATH                   сохранить размеченный кадр
--min-area NUMBER               минимальная площадь контура
--similarity-threshold NUMBER   порог сходства объектов
--debug                         открыть панель визуальной отладки
--debug-output PATH             сохранить панель визуальной отладки
```

Для закрытия окна результата нажмите любую клавишу.
